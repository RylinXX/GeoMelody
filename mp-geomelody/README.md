# GeoMelody 微信小程序源码工程包

本工程是 **GeoMelody（地球旋律）** 的官方微信小程序端完整工程。已打通 3D 地球漫游、Suno 原创高品质音乐播放、微信锁屏后台听歌、微信好友/朋友圈一键卡片分享与关于页面。

---

## 目录结构

```text
mp-geomelody/
├── app.js               # 小程序入口生命周期、后台音频管理器 (BackgroundAudioManager)
├── app.json             # 全局页面路由与权限配置 (包含 audio 后台播放权限)
├── app.wxss             # 全局暗色调 Glassmorphism 设计系统
├── project.config.json  # 微信开发者工具配置文件
├── sitemap.json         # 微信搜索索引配置
├── images/              # 高清品牌透明 Logo 与图标
├── pages/
│   ├── index/           # 首页：3D 全景漫游 WebView 容器，支持深度分享参数传递
│   ├── player/          # 原生播放器：黑胶唱片旋转动效、锁屏状态同步、进度调节
│   └── about/           # 关于我们：功能特性介绍、官网复制、微信意见反馈
└── README.md            # 本使用与上线部署文档
```

## 极速上手使用指南（3 分钟运行）

### 步骤 1：下载并打开微信开发者工具
1. 下载并安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)；
2. 打开微信开发者工具，选择 **「小程序」** -> 点击 **「导入」**（或 **「+」新增**）；
3. **项目目录**：选择当前工程中的 `mp-geomelody` 文件夹；
4. **AppID**：
   * 如果已有小程序账号，填入你的 `wx...` AppID；
   * 如果还没有账号，可以直接选择 **「测试号 / 游客模式」** 进行本地全功能预览；
5. 点击 **「确定」** 即可立即启动 3D 地球仪漫游！

## 微信公众平台后台配置（上线前必备）

登录 [微信公众平台 (mp.weixin.qq.com)](https://mp.weixin.qq.com/)：

1. **配置业务域名（极为重要）**：
   * 进入「开发」->「开发管理」->「开发设置」->「业务域名」；
   * 点击修改，将 `etgq.com` 添加为业务域名（下载校验文件放置于服务器根目录即可）。
2. **配置服务器合法域名**：
   * 进入「request 合法域名」与「downloadFile 合法域名」；
   * 添加：`https://etgq.com`。

## 小程序核心技术亮点

1. **锁屏/后台灭屏不间断听歌**：
   * 采用微信原生 `wx.getBackgroundAudioManager()`，手机锁屏或微信切到聊天界面时，音乐依然流畅播放，并支持在手机控制中心切歌与查看胜景封面。
2. **一键生成微信群/朋友圈分享卡片**：
   * 在地球仪上浏览任意景点，点击右上角转发即可自动带上该景点的专属 4K 封面和专属标题。
3. **云端实时同步与热更新**：
   * 只要在服务器更新了新景点或新音频，小程序用户端无需重新发版，即时加载最新云端内容。

## 提交审核与发布

1. 在微信开发者工具右上角点击 **「上传」**，填写版本号（如 `1.0.0`）；
2. 登录微信公众平台后台 ->「版本管理」-> 提交审核；
3. **类目推荐**：建议选择 `工具 > 旅游攻略`、`工具 > 信息查询` 或 `文娱 > 资讯/音频`；
4. 审核通过后，点击 **「全量发布」**，所有微信用户即可在微信下拉列表中搜索并使用 GeoMelody！
