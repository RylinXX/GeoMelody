# GeoMelody demo audio attribution

- `peaceful.ogg` — “Peaceful” by Tamlin Lollis Love, licensed under CC BY-SA 3.0. Source: https://commons.wikimedia.org/wiki/File:Peaceful.ogg
- `chill-beat.ogg` — “Chill Beat” by Maddy, dedicated to the public domain under CC0. Source: https://commons.wikimedia.org/wiki/File:Chill_Beat.ogg
- `moonlight-sonata.ogg` — Beethoven’s “Moonlight Sonata”, first movement. Public-domain composition and recording as described by the source. Source: https://commons.wikimedia.org/wiki/File:Moonlight_Sonata.ogg

These files are included only as prototype reference tracks. The interface displays the title, creator, license, and source link while a track is in use.
