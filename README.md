# 境音地图 · GeoMelody
**以地图探索世界，用声音感受地方。**

GeoMelody 是一个以地理位置为入口的视听探索项目，将三维地图、地点内容、音频播放与社区交互结合。这个品牌仍贴合产品，因此保留 GeoMelody 名称，而不是为了改名改动品牌。

[线上体验](https://etgq.com/)

## 体验组成

- 地图与地点探索：从全球地理视角进入具体地点。
- 音频与播放器：关联地点内容和声音体验。
- 内容与交互：页面中的社区及相关功能由现有前后端实现。
- 小程序实验：`mp-geomelody/` 保留独立小程序代码，不等同于网页构建产物。

声音、图片和地理素材的可用性受资源配置、网络服务与授权限制影响；不能把演示内容理解为实时地理实况。

## 技术与目录

Vite、JavaScript、Three.js、MapTiler SDK，另有 Python 服务处理站点 API。

```text
src/          地图、播放器、音频与页面逻辑
public/       静态资源
server/       Python API 与服务配置
mp-geomelody/ 小程序版本
scripts/      辅助工具
```

## 本地开发

安装现代 Node.js，在根目录运行：

```sh
npm ci
npm run dev
npm run build
```

按地图服务要求配置开发密钥和允许的来源域名。浏览器侧地图密钥不能当作服务器秘密使用；应配置来源与配额限制。需要社区等 API 功能时，按 `server/geomelody-api.service` 对应的程序启动独立服务，并检查开发代理设置。

## 生产部署

生产域名是 `etgq.com`；静态前端由 Nginx 提供，`/api/` 转发到本机 Python 服务的 8765 端口。发布前构建，再替换前端产物；不要直接拿压缩后的线上 JavaScript 反写源文件。

保留 `server/data/` 和 `server/uploads/` 等运行数据。代码仓库不是用户内容备份，数据库、上传文件、日志和密钥单独管理。上线前检查地图资源、播放器、API、移动布局和跨域配置。
